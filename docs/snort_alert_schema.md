# Snort Alert Schema (`snort.alert`)

## Overview

This dataset contains IDS alert logs generated by **Snort**, normalized to follow **Elastic Common Schema (ECS)** conventions where practical.

Each record represents a single Snort alert event parsed from the MACCDC 2012 full alert text logs.

---

## Fields

### Event Metadata

| Field            | Type      | Description                                                |
| ---------------- | --------- | ---------------------------------------------------------- |
| `@timestamp`     | date      | Alert timestamp (ISO-8601, derived from Snort log text)    |
| `event.kind`     | keyword   | Type of event (always `alert`)                             |
| `event.category` | keyword[] | Event category (always `intrusion_detection`)              |
| `event.type`     | keyword[] | Event type (currently `info`)                              |
| `event.module`   | keyword   | Module name (`snort`)                                      |
| `event.dataset`  | keyword   | Dataset name (`snort.alert`)                               |
| `event.severity` | integer   | Snort priority when classification metadata is present     |
| `message`        | text      | Human-readable rule message                                |
| `event.original` | text      | Raw Snort alert block                                      |

---

### Rule

| Field           | Type    | Description                                |
| --------------- | ------- | ------------------------------------------ |
| `rule.id`       | keyword | Rule identifier in `gid:sid:rev` format    |
| `rule.name`     | keyword | Rule message text                          |
| `rule.category` | keyword | Snort classification text, when available  |

---

### Source

| Field         | Type    | Description         |
| ------------- | ------- | ------------------- |
| `source.ip`   | ip      | Source IP address   |
| `source.port` | integer | Source port         |

---

### Destination

| Field              | Type    | Description              |
| ------------------ | ------- | ------------------------ |
| `destination.ip`   | ip      | Destination IP address   |
| `destination.port` | integer | Destination port         |

---

### Network

| Field               | Type    | Description                                |
| ------------------- | ------- | ------------------------------------------ |
| `network.transport` | keyword | Transport protocol (e.g. `tcp`, `udp`)     |

---

### Snort-Specific Fields

| Field                       | Type    | Description                                      |
| --------------------------- | ------- | ------------------------------------------------ |
| `snort.generator_id`        | integer | Snort generator ID                               |
| `snort.signature_id`        | integer | Snort signature ID                               |
| `snort.signature_revision`  | integer | Snort rule revision                              |
| `snort.ip.ttl`              | integer | IP time-to-live value                            |
| `snort.ip.tos`              | keyword | IP type-of-service value                         |
| `snort.ip.id`               | integer | IP packet ID                                     |
| `snort.ip.len`              | integer | IP header length                                 |
| `snort.ip.flags`            | keyword | IP flags summary when present                    |
| `snort.packet.len`          | integer | Datagram length                                  |
| `snort.tcp.flags_raw`       | keyword | Raw TCP flags string from the alert text         |
| `snort.tcp.seq`             | keyword | TCP sequence number in hex                       |
| `snort.tcp.ack`             | keyword | TCP acknowledgement number in hex                |
| `snort.tcp.window`          | keyword | TCP window size in hex                           |
| `snort.tcp.len`             | integer | TCP header length                                |
| `snort.xref`                | keyword | External rule reference URL or identifier        |
| `snort.extra`               | keyword[] | Additional unparsed trailing lines, when present |

---

### Related And Log Context

| Field            | Type      | Description                         |
| ---------------- | --------- | ----------------------------------- |
| `related.ip`     | ip[]      | IPs involved in the alert           |
| `log.file.path`  | keyword   | Source alert file path              |

---

## Notes

* Some fields may be absent when the corresponding Snort block lines are missing.
* `event.severity` is taken from Snort `Priority`.
* `rule.category` is taken from Snort `Classification`.
* The parser currently sets `event.type` to `info` for all alerts.
* `related.ip` contains both source and destination IPs when they are present.

---

## Example

```json
{
  "@timestamp": "2012-03-16T07:30:00",
  "event.kind": "alert",
  "event.category": ["intrusion_detection"],
  "event.type": ["info"],
  "event.module": "snort",
  "event.dataset": "snort.alert",
  "rule.id": "1:2009358:5",
  "rule.name": "ET SCAN Nmap Scripting Engine User-Agent Detected (Nmap Scripting Engine)",
  "event.severity": 1,
  "source.ip": "192.168.202.79",
  "destination.ip": "192.168.229.251",
  "network.transport": "tcp",
  "snort.signature_id": 2009358
}
```
