# Zeek Connection Log Schema (`zeek.conn`)

## Overview

This dataset contains network connection logs generated by **Zeek**, normalized to follow **Elastic Common Schema (ECS)** conventions.

Each record represents a single network connection (session) between a source and a destination.

---

## Fields

### Event Metadata

| Field            | Type      | Description                      |
| ---------------- | --------- | -------------------------------- |
| `@timestamp`     | date      | Event timestamp (UTC, ISO-8601)  |
| `event.kind`     | keyword   | Type of event (always `event`)   |
| `event.category` | keyword[] | Event category (e.g., `network`) |
| `event.type`     | keyword[] | Event type (e.g., `connection`)  |
| `event.module`   | keyword   | Module name (`zeek`)             |
| `event.dataset`  | keyword   | Dataset name (`zeek.conn`)       |
| `message`        | text      | Human-readable summary           |
| `event.original` | text      | Raw Zeek log line                |

---

### Source

| Field            | Type    | Description              |
| ---------------- | ------- | ------------------------ |
| `source.ip`      | ip      | Source IP address        |
| `source.port`    | integer | Source port              |
| `source.bytes`   | long    | Bytes sent from source   |
| `source.packets` | long    | Packets sent from source |

---

### Destination

| Field                 | Type    | Description                   |
| --------------------- | ------- | ----------------------------- |
| `destination.ip`      | ip      | Destination IP address        |
| `destination.port`    | integer | Destination port              |
| `destination.bytes`   | long    | Bytes sent from destination   |
| `destination.packets` | long    | Packets sent from destination |

---

### Network

| Field               | Type    | Description                                   |
| ------------------- | ------- | --------------------------------------------- |
| `network.transport` | keyword | Transport protocol (e.g., `tcp`)              |
| `network.protocol`  | keyword | Application protocol (e.g., `http`, nullable) |
| `network.bytes`     | long    | Total bytes (source + destination)            |
| `network.packets`   | long    | Total packets (source + destination)          |

---

### Zeek Connection Fields

| Field                      | Type      | Description                             |
| -------------------------- | --------- | --------------------------------------- |
| `zeek.conn.uid`            | keyword   | Unique connection ID                    |
| `zeek.conn.service`        | keyword   | Detected service (nullable)             |
| `zeek.conn.duration`       | float     | Connection duration (seconds, nullable) |
| `zeek.conn.state`          | keyword   | Connection state (e.g., `SF`, `SH`)     |
| `zeek.conn.history`        | keyword   | TCP history flags                       |
| `zeek.conn.missed_bytes`   | long      | Missed bytes count                      |
| `zeek.conn.local_orig`     | boolean   | Local origin flag (nullable)            |
| `zeek.conn.tunnel_parents` | keyword[] | Parent tunnel connections               |

---

### Related

| Field        | Type | Description          |
| ------------ | ---- | -------------------- |
| `related.ip` | ip[] | List of involved IPs |

---

## Notes

* `network.bytes = source.bytes + destination.bytes`
* `network.packets = source.packets + destination.packets`
* `zeek.conn.uid` can be used for correlation
* Some fields may be `null` if Zeek cannot infer values

---

## Example

```json
{
  "@timestamp": "2012-03-16T12:30:00Z",
  "source.ip": "192.168.202.79",
  "source.port": 50465,
  "destination.ip": "192.168.229.251",
  "destination.port": 80,
  "network.transport": "tcp",
  "network.protocol": "http",
  "network.bytes": 380,
  "zeek.conn.state": "SF"
}
```
